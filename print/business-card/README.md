# Fabio Cavagna business card

Print-ready files (dark theme):

- `fabio-cavagna-business-card-duplex.pdf`: preferred file for duplex printing.
- `fabio-cavagna-business-card-front.pdf`: front side only.
- `fabio-cavagna-business-card-back.pdf`: back side only.

Print-ready files (light theme, white background):

- `fabio-cavagna-business-card-duplex-light.pdf`: preferred file for duplex printing.
- `fabio-cavagna-business-card-front-light.pdf`: front side only.
- `fabio-cavagna-business-card-back-light.pdf`: back side only.

Specifications:

- Final trim size: 85 x 55 mm.
- Bleed: 3 mm on each side.
- PDF page size including bleed: 91 x 61 mm.
- Printing: double-sided, matte paper, 300-400 gsm.
- The QR code points to `https://fabiocavagna.com`.

If the print shop asks for separate sides, use the front and back PDFs. If it accepts a two-page duplex PDF, use the duplex file.
